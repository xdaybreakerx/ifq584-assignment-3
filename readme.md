## Using the App

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download) installed on your system.
- To confirm the version of .NET on your computer, open a terminal and execute the following command.

```bash
dotnet --version
```

### Build and Run Instructions

1. Open a terminal in the project root (./NumericalticTacToe_XANDER_SALATHE)
2. Clean previous build artifacts and compile application.
    ```bash
    dotnet clean
    dotnet run
    ```
